# Документация MicroSchema

В этом разделе описаны архитектура, расширение и внутренние механизмы MicroSchema.

## Разделы

- [Разрешение схем](schema-resolution.md) — путь контекста, кандидаты, переопределения пунктов меню, сбор и вывод
  разметки;
- [Пользовательские типы метаданных](extending-metadata.md) — создание и регистрация дескрипторов Schema.org и
  социальных метаданных;
- [Пользовательские источники и типы данных](data-sources.md) — источники значений, типы данных, коллекции и
  интеграция с Joomla.

Код, имена API, машинные идентификаторы, параметры и форматы приводятся в исходном виде, поскольку являются
частью программного контракта расширений.
