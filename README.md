# MicroSchema для Joomla

MicroSchema — набор расширений для Joomla, который формирует структурированные данные Schema.org в формате
JSON-LD и социальные метаданные. Архитектура позволяет интеграционным плагинам добавлять поддержку компонентов и
новых типов разметки без изменения ядра расширения.

## Требования

- Joomla 5.4 или Joomla 6.x;
- PHP 8.2 или новее;
- расширение PHP SimpleXML.

## Состав проекта

- `com_microschema` — компонент с общей конфигурацией, реестрами, редактором свойств и средствами вывода;
- `plg_system_microschema` — системный плагин, который собирает и добавляет разметку на страницу;
- `plg_microschema_content` — интеграция с материалами и категориями `com_content`;
- `plg_microschema_contact` — интеграция с контактами и категориями `com_contact`;
- `mod_microschema` — модуль для добавления отдельной Schema.org-схемы в общий сборщик.

Отдельно распространяется `plg_system_microschemayootheme` — системный плагин с элементом MicroSchema для
YOOtheme Pro Builder. Плагин не входит в пакет `pkg_microschema` и устанавливается пользователем отдельно.

## Возможности

- формирование нескольких независимых JSON-LD-схем;
- наследование и переопределение настроек по контексту страницы;
- проверка существующей Schema.org-разметки перед выводом;
- формирование социальных метатегов;
- шаблоны значений с источниками данных Joomla;
- расширение типов метаданных, источников данных и интеграций через плагины.

## Разработка

Для сборки административных ресурсов используются Node.js, Rollup и Vue. Доступные команды управления локальным
окружением описаны в `Makefile`. Перед запуском сборки установите зависимости проекта подходящим для вашего
окружения способом.

Плагин для YOOtheme Pro собирается независимо от основного пакета командой `make build-yootheme-plugin`.

### Тесты

PHP-тесты запускаются через Codeception. Быстрый набор не требует работающей Joomla:

```shell
make test-unit
```

Функциональные тесты используют настоящие HTTP-точки входа Joomla, тестовую базу данных и
`sovmart/codeception-module-joomla`. Они предназначены только для изолированного локального окружения:

```shell
make up
make test-functional
```

Полный быстрый прогон PHP- и JavaScript-тестов:

```shell
make test
```
